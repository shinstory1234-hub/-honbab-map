# 아파트맵 반응성 개선 검증

2026-11-09. 기준 커밋 `1e675daa66fb65c11cb581987747292ea2198561`.

## 변경 내용

- 주변 단지 급지 계산에서 전체 단지 쌍 대신 1.5km 범위를 덮는 격자 후보만 조회한다. 후보 합산 순서를 유지한다.
- 주변 시세 계산은 좌표, 연식, 비교 연식, 지역코드가 같으면 결과를 재사용한다. 연식 기준 20년과 25년의 공통 거리 탐색도 공유한다.
- 같은 좌표와 역 자료, 보행 경로의 교통 계산을 재사용한다. 예정 역 자료, 좌표 또는 보행 자료가 바뀌면 새 값으로 계산한다.
- 이미 반영된 예정 역 좌표와 변동 없는 지형 자료 때문에 초기 계산을 반복하던 두 경로를 제거한다.
- 지도 표시는 실제 화면에 나타날 때 생성하고, 여러 지도 갱신 요청을 한 프레임으로 합친다.

가격, 평가 비중, 제외 대상, 추천 순위 정책은 변경하지 않았다. 가격 이상 의심 평형의 추천 보류 기능은 이 변경에 포함하지 않았다.

## 동일 결과 및 시간 비교

동일한 저장 시세와 지리 자료를 사용해 실제 페이지 스크립트를 Node VM에서 실행했다. 시간은 한 환경의 단일 비교 실행이며, 통신 지연이나 휴대폰 브라우저의 체감 로딩 시간을 나타내지는 않는다. 초기 처리는 파일 읽기, 스크립트 실행, 첫 재계산과 결과 직렬화를 포함한다.

전체 가격대의 가격, 점수, 순위, 교통 후보, 급지, 주변 시세, 상세 적정가, 재건축 계산, 순위 범위를 비교했다. 반복 재계산과 좌표, 역 거리, 보행 경로, 예정 역 좌표를 바꾼 뒤의 결과도 대조했다. 6억 이하 5,822개 평형을 포함해 전부 일치한다.

지도 테스트에서는 2,000개 후보를 등록한 뒤, 이동과 확대, 선택, 필터 적용 시 표시되는 후보가 기존과 동일했다. 기존은 2,000개 표시 객체를 즉시 생성했고 수정본은 테스트 중 실제 보인 100개만 생성했다. 연속 갱신 요청이 한 프레임으로 합쳐지는 것도 확인했다.

브라우저에서 가격대 전환, 단지 검색과 상세 진입을 확인했다. 로컬 미리보기는 카카오 지도를 불러오지 못하므로 실제 지도는 배포된 등록 도메인에서 별도로 확인한다.

재현:

```sh
node scripts/test-apt-performance.mjs <기준 소스> <수정 소스>
node scripts/test-apt-map-pins.mjs <기준 소스> <수정 소스>
```

상위권 순위의 남은 문제는 대표가격 신뢰성이다. 6~10억에서 DMC아트포레자이 30평과 e편한세상염창 일부 평형은 가격 근거 확인이 끝나기 전까지 확정 추천으로 보기는 어렵다. 이번 성능 개선이 그 가격 문제를 해결했다는 의미는 아니다.
