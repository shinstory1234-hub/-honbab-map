# 30억 이상 상위 300개 리치고 기준 전수 대조 및 추가 수정

검증 기준일: 2026-11-18. 전용 브랜치에서만 처리. 운영 사이트 및 다른 가격대는 수정하지 않음.

## 검증 현황

| 항목 | 건수 |
| --- | ---: |
| 조사 대상 | **300** |
| 리치고 개별 단지 대조 | **286** |

종전 검증 미완료 77개 중 **76개**의 리치고 공개 단지 상세페이지와 실제 대응 단지를 확인했다. 63개는 개별 단지로 확정하고 리치고 세대수, 준공연도, 용적률 및 좌표를 적용했다. 이 중 기존 세대수와 다른 값 **29개를 수정**했다.

나머지 13개는 리치고가 차수를 합쳐 표기한 경우다. 리치고 용적률과 입주연도 및 위치를 대조해 적용하되, 통합 세대수를 각 하위 단지에 똑같이 중복 입력하지 않았다. 대표적으로 압구정 신현대 9·11·12차, 개포우성 1·2차, 선경1·2차, 용산파크타워가 있다.

**에테르노청담 1개는 리치고의 개별 공개 단지 상세페이지가 확인되지 않아 원본을 유지했다.** 공개 페이지에서도 공란인 용적률 25개는 임의 값을 입력하지 않았다.

## 추가 정정 사례

- 잠원동 동아: 이전 600세대 자료의 잘못된 매칭을 리치고 잠원동 동아 991세대 단지로 수정.
- 대치삼성: 35세대 대치삼성3차와의 혼동을 대치삼성1차 960세대 자료로 정정.
- 서빙고동 신동아, 개포동 현대2, 여의도 한양·미성: 잘못된 원본 위치를 리치고 주소와 좌표로 재확인해 수정.
- 광교e편한세상: 442세대인 2차의 잘못된 연결을 1,970세대 본 단지로 변경.
