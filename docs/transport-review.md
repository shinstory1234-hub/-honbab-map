# 교통 접근성 5% 개편 검토 결과

기준일: 2026-11-04. 기준 커밋: `b723a3cfefd1f3c24fb69fef68bbcb765bf458a7`.

## 변경 범위와 검증

- 6억 초과 다섯 가격대만 세대수 25% + 장기 급지 50% + 상품성 20% + 교통 5% 적용.
- 6억 이하 5,822개 평형의 원점수·순위·평형 목록·대표 여부·평가 구성 전체를 전후 JSON 완전 일치 비교로 검증했다. 기존 `apt-s4q.js`와 전용 자료는 수정하지 않았다.
- 6억 초과 2,801 / 1,993 / 1,125 / 558 / 255개 평형 전체에서 독립적으로 산식을 계산해 대조했다. 대표 단지는 각각 1,434 / 1,077 / 649 / 367 / 184개다. 가격대 사이 중복 단지는 있을 수 있다.
- 세대수·장기 급지·상품성 원점수, 소형 보정, 평당가 보정, 언덕 감점, 초대형 가점, 재건축 위험 관련 기존 요소가 보존됨을 확인했다. 모든 신규 교통점수는 0~100점, 종합 기여는 0~5점, 기존 역 거리 감점은 0이다.
- 대표 평형은 가격대 안에서 가장 높은 점수인 평형이다. 단지별 중복 제거 후 순위가 1부터 연속이고 원점수 내림차순임을 검증했다.
- S~D 지정 계수, 표기 변형, 도보 경계값, 거리 증가에 따른 감소, 실측 우선, 환승역 최고 계수, 여러 역 최고점, 예정 노선 할인, 미확정 노선 제외를 자동 검증했다.
- 실제 입력의 24종 운행 노선 표기는 전부 등급이 배정됐다. 우이신설선·인천1/2호선 등은 D등급이다. 이전 입지 참고 점수의 노선계수는 건드리지 않았다.
- Next.js 프로덕션 빌드 통과. 390px iframe에서 모바일 검색·상세 진입·교통 산식 표시를 확인했다. 실제 휴대전화 검증은 아니다. 미리보기 주소에서는 카카오 지도 로딩이 실패했으므로 지도 동작은 운영 주소에서 별도 확인해야 한다.

## DMC SK뷰아이파크포레

| 구간 | 대표 평형 | 이전 순위 | 이후 순위 | 이전 점수 | 이후 점수 |
|---|---:|---:|---:|---:|---:|
| 6~10억 | 22평 | 1 | 2 | 69.494935 | 68.154112 |
| 10~15억 | 24평 | 22 | 37 | 71.544877 | 70.204054 |

기존 운영 화면과 같은 입력을 사용해 기존 1위를 재현했다. 숫자 정렬 오류나 특정 단지의 인위적 우대·감점을 발견한 것은 아니다. 수색역 경의중앙선(C, 0.3), 저장 직선거리 671m, 추정 도보 10.484375분이 최적 선택이며 교통 28.546875점, 종합 기여 1.42734375점이다. 기존 가중치 변경과 역 거리 감점 제거까지 합쳐 점수가 변한다. 높은 순위는 이 모델의 상대평가이며 매수 적정성이나 미래 수익을 보장하지 않는다.

최고점 대표 평형 선정과 단지 키 중복 제거 로직은 유지했다. 6억 초과 탭에서 계산 전에 보이던 `apt-first*.js` 고정 순위 미리보기는 로딩 대상에서 제외했다. 실제 계산이 끝난 순위만 표시한다. <=6억 미리보기는 그대로다. 상세 순위 분모도 >6억은 평형 수가 아닌 단지 수로 표시한다.

## 입력·가정·한계

실제 보행 경로 시간 자료는 현재 입력에서 찾지 못했다. 모두 직선거리 × 1.25 ÷ 80으로 추정하며 화면에 '추정 도보'로 표시한다. 향후 `APT_STATION_WALKS[단지키][역·노선]`에 minutes/source/checkedAt이 있는 경로 자료가 들어오면 우선 사용한다. 단지 대표점·역 좌표 기준이므로 관심 동 현관부터 승강장까지의 실측 시간이 아니다.

예정 사업은 기존 FUT의 좌표와 확정 사업 목록을 사용하며, 연 5%·최대 20% 할인이라는 기존 규칙을 유지했다. 할인 기준연도도 기존 모델과 동일한 2026년이다. 목표연도가 지났다고 자동으로 운행 중으로 바꾸지 않는다. GTX-B/C는 운행 중으로 인정하지 않으며, >6억 모듈에서 최신 공단 사업기간인 2031년 목표를 사용한다. 회천중앙역은 2030년 목표를 사용한다. 다른 예정 연도는 기존 저장 자료를 사용하며 확정 개통일이 아니다.

GTX-A는 개통한 9개 역만 운영 역으로 인정한다. 기존 거리 자료에서 노선만 빠진 수서·구성 등 환승역에는 GTX-A를 보완한다. 같은 역의 기존 거리 자료를 사용하는 추정이다. 기존 입력에 역 좌표·거리 자체가 없는 역을 새로 지어내지는 않았다. 삼성·창릉은 운영 역으로 인정하지 않는다. 따라서 결과는 저장된 주변 역과 예정 역 데이터 범위에 한정된다.

## 전체 순위 결과와 재현

`transport-comparison.md`: 각 가격대 수정 전후 상위 20, 최대 상승/하락 각 20, DMC, 신분당선·경의중앙선 추정 도보 20분 이내 단지, 전후 상위 100 합집합.

`transport-comparison.json.gz`: 위 결과와 가격대별 전체 대표단지 순위, 점수, 선정 역 및 평가계수. `inputs`에 운영 입력 SHA-256 포함.

동일 시점의 공개 운영 입력은 `transport-inputs/*.js.gz`에 보관한다. 임시 디렉터리에 압축을 해제하고 아래 명령을 사용한다. 기준 체크아웃은 위 기준 커밋으로 준비한다.

```sh
TRANSPORT_INPUTS=/path/to/unpacked-inputs node scripts/test-transport.mjs /path/to/baseline .
TRANSPORT_INPUTS=/path/to/unpacked-inputs node scripts/test-transport-ui.mjs .
npm run build
```

운영 시세는 매일 갱신될 수 있으므로 다른 시점의 순위를 섞어서 변경 효과로 해석하면 안 된다.
