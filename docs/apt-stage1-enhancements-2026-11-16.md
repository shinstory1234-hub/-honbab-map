# 아파트맵 1단계 기능 보강 및 데이터 출처

- 작업일: 2026-11-16.
- 원칙: 기존 추천 순위와 점수, 가격대별 초기 전송량 예산, 6억 이하 기존 모델 변경 금지.
- 초기 페이지에는 신규 시설·학교 원시자료를 실지 않는다. 상세 화면 또는 사용자의 지도 호재 보기 클릭 시 추가 스크립트를 로드한다.

## 1. 초등학교 통학구역
2026-09-20 한국교육시설안전원 공개 초등학교 통학구역 및 공동통학구역 SHP 파일을 다운로드했다.
원본 공공데이터 목록: https://schoolzone.emac.kr/publicData/publicDataList.do
파일: `/publicData/publicDataFileDownload.do?nttId=2966&atchFileId=FILE_000000100002996&fileSn=0`.
공간 좌표계: EPSG:5186. 아파트맵의 단지 대표점 5,340개를 EPSG:4326→EPSG:5186 변환한 후 통학구역 폴리곤 포함 여부로 대사했으며, 수도권 폴리곤 2,660개, 일치 5,340개, FNV-1a(UTF-8) 키 해시 충돌 0개를 확인했다. 단지 구분명 변경이나 새 단지에는 미일치가 가능하다.

전수자료는 Brotli 압축되어 `lib/apt-schoolzone-202609.br.part0...6`에 저장한다. 서버가 `GET /api/apt-school?k=단지명|지역명`으로 선택 단지 정보만 제공한다. 폴리곤은 통학구역이며 동·호별, 공동학구, 교육지원청의 최종 입학 배정 확인을 대체하지 않는다.

## 2. 보행시간·생활권
카카오 장소 검색의 시설 위치와 OSM Valhalla 보행 네트워크를 조합한다. 경로·15분 보행권은 `GET /api/apt-walk-route`로 선택시만 계산하고 7일 캐시한다. 동·역 출입구 좌표를 확보하지 못한 단지는 대표점 좌표를 쓰며, 단지 출입구~개찰구 정확 시간이 아니다. 서버 접속이 제한되면 수치를 만들지 않는다.

## 3. 상세 추가 모듈
`lib/apt-stage1-extra.br.part0...1`은 `public/apt-stage1-extra.js`를 Brotli 압축한 읽기 전용 분할 산출물이다. `npm run build` 시 `scripts/build-apt-assets.mjs`에서 완전한 JS를 복원한다. 원본을 갱신할 때는 합쳐진 JS를 수정, Brotli 압축 후 6,750바이트 단위로 동일한 조각들을 재생성한다. 최초 렌더 파일에는 포함하지 않는다.

## 4. 확인되지 않은 정보
현재 최저 호가는 연동하지 않는다. 세대별 실측 대지권, 공식 조합 분담금, 층수, 주차, 난방, 시공사 등 원시자료가 없으면 미확인으로 표기한다. 예정역·택지 위치는 확정 노선·구역 폴리곤이 아닌 위치 안내일 수 있다. 학교·용적률·세금은 산출 자료와 확정 원문을 구분한다.
