# 25억 초과~30억 이하 리치고 원자료 대조 — 2026-11-18

## 작업 범위 및 실제 상태

- 별도 브랜치: `audit/richgo-25to30-top300-20261118`. `master` 및 운영 배포는 변경하지 않는다.
- `apt-univ30.js`의 정적 원본에서 25억 초과~30억 이하 평형이 하나라도 있는 단지 **139곳**을 1차 후보로 추렸다. 후보 CSV의 `snapshot_seq_not_rank`는 원본 배열 순번이며 **실시간 순위가 아니다**.
- 공개 리치고 단지 페이지를 직접 확인하고 동일 지역·입주 연도·세대수가 일치한 **14곳**에 대해서만 용적률을 검증했다.
- 추가 **3곳**은 리치고와 세대수가 크게 달라 단지 전체와 부분 건물 매칭 문제로 판단해 자동 이식을 보류했다.
- 과거 2026-11-16 대조 자료에 들어 있는 **20곳**은 이번 직접 검증에 포함하지 않았고 별도로 재확인 대상으로 표시했다. **102곳**은 직접 확인하지 못했다.
- **상위 300개 실제 실시간 순위 추출, 전체 300곳 리치고 전수대조는 아직 수행하지 못했다.** `apt-live.js` 시세에 따라 현재 표시 단지와 순위가 달라질 수 있다. 정적 자료 139곳은 상위 300곳의 완료를 의미하지 않는다.

## 반영 방법

- **단지명+행정구역+입주연도+세대수**가 직접 확인된 14곳의 용적률만, 25~30억 탭(`CAPT===30`)의 마지막 정규화 다음에 덮어쓴다.
- `apt-richgo30-fix.js`만 해당 탭에서 추가로 로드하며, 6억 이하~20~25억 탭과 30억 이상 탭에서는 로드하지 않는다.
- 리치고가 **공란**이거나 **세대수 불일치**면 수치를 임의로 만들거나 적용하지 않는다. 기존 실거래 가격·대표 평형은 리치고 추정시세와 산출 기준이 달라 자동으로 바꾸지 않는다.
- 새 조회값은 공개 단지 상세 페이지에 나온 용적률만 사용했고 외부 사이트의 데이터 묶음·무단 API 대량수집은 진행하지 않았다. 출처 페이지는 후보 CSV에 기록한다.

## 주의사항
