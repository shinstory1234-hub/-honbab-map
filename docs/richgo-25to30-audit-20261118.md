# 25억 초과~30억 이하 리치고 원자료 대조 — 2026-11-18

## 수행 범위와 정확한 상태

- 작업 브랜치: `audit/richgo-25to30-top300-20261118`. `master` 및 운영 환경 미반영.
- 아파트맵 정적 원자료에서 25억 초과~30억 이하 평형을 하나라도 포함한 **139개 단지** 추출. CSV의 `snapshot_seq_not_rank`는 데이터 배열 번호이며 **실시간 순위가 아니다**.
- 리치고 단지 페이지를 직접 확인해 세대수와 준공연도가 일치하는 **14곳**의 용적률을 대조했다.
- 기존 파일의 건축물대장·기존 보정 스크립트까지 반영한 **실제 최종 용적률**은 14곳 중 **12곳 이미 리치고와 같았고**, **2곳만 불일치**했다. 불일치 2곳은 `apt-univ30.js` 원자료를 리치고 값으로 교체했다.
- 단지명은 비슷하지만 세대수가 서로 다른 **3곳**(경희궁의아침 2·3·4단지)은 합산 단지와 개별 건물 간 혼동 가능성이 높아 자동수정하지 않았다.
- 이전 2026-11-16 대조에서 **20곳**은 단지 동일성이 미확정이므로 재검토 대상으로만 표시했다. 나머지 **102곳**은 직접 확인하지 못했다.
- **실시간 순위 상위 300곳 전수대조는 아직 미완료**다. 아파트맵의 실시간 시세가 이동하면 정적 후보 139곳 외에도 표시 대상이 생길 수 있다. 이 작업을 300개 완료로 표현하지 않는다.

## 실제 수정

1. 경희궁자이(2단지), 서울 종로구 홍파동: 기존 용적률 **253% → 252%** (리치고 1,148세대, 2017년).
2. 서울숲리버뷰자이, 서울 성동구 행당동: 기존 용적률 **281% → 280%** (리치고 1,034세대, 2018년).
3. 직접 확인한 나머지 12곳은 아파트맵 실효 용적률이 이미 일치하여 기존 값을 유지했다.

리치고 단지 링크와 검증 상태는 `richgo-25to30-audit-20261118.csv`에 있다. CSV의 `map_far_before_normalization`은 **수정 전 원본 배열**로서, 나중에 실행되는 보정 스크립트의 최종 수치를 뜻하지 않는다. 특히 원본 공란이더라도 실제 사이트에서 보정되어 값이 표시되는 경우가 있다.

## 배포·성능·타 구간 보호

- 수정은 25~30억 해당 정적 데이터의 단지 2곳에 한정한다. 단, 단지 데이터는 여러 가격대가 공유하기 때문에 추후 다른 가격대에서 같은 단지가 보이면 **동일한 올바른 용적률**을 사용한다.
- 가격·면적·세대수·준공연도·산정 방식·순위 가중치와 6억 이하 데이터를 변경하지 않았다.
- 새 자바스크립트나 HTML 로더는 추가하지 않았다. `scripts/perf-budget.json`과 기존 예산 검사는 그대로 둔다.
- `node scripts/test-richgo25to30-verified.cjs`, `npm run build`로 검사한다.

## 대량 대조 시 참고

리치고 공개 MCP 설명에는 전국 아파트 단지의 대량 수집은 무료 MCP가 아닌 파트너 REST API를 사용하도록 안내한다. 따라서 300곳 일괄 수집을 우회 구현하지 않았으며 정식 제공 범위와 이용 조건 확인이 필요하다.
