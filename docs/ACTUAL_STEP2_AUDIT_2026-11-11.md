## 확인된 실제 결함: 가격대 예외 누출
- 단지: `수원센트럴아이파크자이`, 17평, 저장 시세 `40,075만원`(4억 75만원).
- `public/apt-picks.js`의 `window.OPT`는 이 단지에 별도 확정가 매수권/민간임대 추정 정보를 추가한다.
- `public/apt-map.html`에서 `opt:(window.OPT||{})[d.n]||null`은 모든 가격대에 무조건 주입한다.
- 이후 `.filter(d=>{ if(d.opt||inBand(d.p)) return true; ... })`의 `d.opt` 우회 때문에 **4억인 후보가 6~10억, 10~15억, 15~20억, 20~25억, 25~30억에 모두 혼입**된다.
- 이 결함의 근본 원인은 원본 시세 수치 자체보다 **특수 상품 평가와 일반 아파트 매매 가격대 필터를 혼합**한 것이다.
- 배포 전까지 이 후보는 상위 가격대 추천 목록에서 제외하거나, 실제 매매 가능 평형 시세로 재선정해야 한다. 보호된 6억 이하 로직은 유지해야 한다.

## 재건축 통합구역 A-5에 대한 실제 대조
- 2026-08-31 안양시 공고 제2026-1444호: A-5 특별정비계획안 주민공람. 2026-11-05 평촌 A-5 주민대표단과 한국자산신탁의 예비사업시행자 업무협약 보도. 공람은 구역 지정 완료와 다르다.
- 한가람 한양 `952세대`, 삼성 `708세대`, 두산 `436세대`가 계산에 사용되고 있으며 합계 `2,096세대`는 발표된 기존 총세대수와 **일치한다**. 향후 계획 `2,839세대`를 현행 단지 규모에 그대로 더하면 안 된다.
- 그러나 해당 세 단지의 모델상 정비사업 단계 `stage=0`으로 유지돼 공식 주민공람/통합재건축 추진 기록과 맞물린 설명이 없다.
- 6~10억 구간 한가람한양 24평: 시세 `84,000만원`, **1,143위**, 점수 약 `33.35`, 준공연식 상품성 `29점`, 가격 신뢰도 감점 `13점`, 사업성 경고 계수 `dead≈0.578`. 이 순위는 저장된 실거래·좌표 입력과 2026-11-11 master 코드 조합의 계산 결과이며 실제 운영 화면의 실시간 순위와 다를 수 있다.
- **현재 세대수 원본은 이 단지에서 일치한다.** 문제는 '공식 정비 진척'과 '사업성/분담금 추정'이 분리되지 않은 표현과 M3 점수 연동이다.
- 증빙 출처와 구성: `docs/audit-redevelopment-registry.json`. 실제 후보 교차검사 스크립트: `scripts/audit-apt-project-facts.mjs`.

## 남아 있는 검증 범위
1. 12,600평형의 **코드 산출 값과 저장된 입력 정합성**은 검사했으나, 국토교통부 실거래 API 및 정비사업 공고 DB를 전 단지 대상으로 새로 조회해 원본 자체를 전부 대조한 것은 아니다.
2. 기준이 다른 과거 스냅샷과 최신 단지별 순위의 숫자 차이만으로 과소/과대평가를 확정하지 않는다.
3. 먼저 객관적 원본 오류(가격대, 단지 식별, 사업 단계)를 정정한 후, 별도의 오프라인 검증 브랜치에서 산식 영향과 과거 성과를 확인해야 한다. 배포, 메인 수정, 일괄 가점은 하지 않았다.
