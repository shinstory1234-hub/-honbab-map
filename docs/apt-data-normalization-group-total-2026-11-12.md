# 공동관리단지 세대수 합계 복제 일괄 차단 (2026-11-12)

- 분석 원천 5,095개 고유 단지 전수 중 동일 K-apt 코드의 여러 블록 원천 세대수 합계 = 공식 관리단지 세대수가 정확히 일치하는 집단 15개 발견.
- **6억 초과** 개별 블록에 관리단지 전체 세대수를 재적용하던 보정 **15건 제거**.
- 보정 총계 `643 → 628`. 원천 세대수로 회귀한 15건: 목동센트럴아이파크위브1~4, 북한산래미안1~2, 관악산휴먼시아1~2, 수원모아미래도센트럴타운1~2, 판교퍼스트힐푸르지오1단지 및 A2, 래미안노블클래스1단지, 오포자이디오브3단지, 수원 엘지빌리지3.
- 6억 이하가 포함된 기존 세대수 보정은 하나도 변경하지 않았다. 6억 이하에 포함된 공동관리단지 집계 문제는 별도 검증 대상으로 남긴다.
- 분석 저장소 `analysis/m2/unitfix3.py`에 재생성 방지 규칙 및 `unitfix3_split_audit.json` 추가.
- 기존 가중치, 점수 계산 파일, 실거래가격, 지도 UI 변경 없음.
- 운영 `master` 미반영. 본 변경은 초안 PR의 검토 브랜치에만 반영했다.

세부 검증과 15개 그룹 근거: `realestate-media/analysis/m2/unitfix3_split_audit.json` 및 `analysis/m2/unitfix3_split_report.md`.
