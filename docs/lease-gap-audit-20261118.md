# 전월세 및 갭 기능 점검 (2026-11-18)

기준: master de6f6577aae303c49f1fa7202889b05727d32680

## 확인된 구현
- app/api/apt-rent/route.js: 국토교통부 API 6개월 조회, 법정동·단지명 일치, 최대 3페이지, 24시간 캐시, 일부 실패 시 partial 표기.
- public/apt-stage2.js: d.jeon 값을 사용해 전세가율 = 전세금 / 매매가 × 100, 갭 = 매매가 - 전세금, 상세 필터에 전세금 최소·갭 최대·전세가율 최소/최대 조건 존재.

## 발견된 연결 누락 (수정 필요)
1. apt-stage2.js의 rent(d)는 d.jeon만 참조하며 /api/apt-rent 호출 결과를 사용하지 않음. 따라서 공식 전월세 API와 전세가율/갭 필터는 자동 연결되지 않음.
2. 전세 관련 필터는 전체 D 중 d.jeon 보유율이 60% 이상(최소 50개)일 때만 표시됨. API 결과가 있어도 해당 조건은 자동 변경되지 않음.
3. API는 단지명·법정동만으로 매칭하고, 동일 전용면적 필터링은 화면 책임. 평형이 다르면 잘못된 전세가율 추정 위험.
4. API는 최근 6개월을 조회하고 160건까지만 반환. 전체 거래를 대표한다고 가정할 수 없음.

## 검증 범위
소스 코드 정적 점검 완료. 실제 운영 API 응답, API 인증키 설정, 화면 동작, 빌드 테스트는 미검증. 이 문서는 완료 보고가 아니라 재현 가능한 수정 목록임.

## 구현 권고
- 단지 상세 화면에서 apt-rent 응답을 받아 동일 전용면적(허용오차 명시) 전세 계약만 집계.
- 전세 실거래가 없거나 부분 실패인 경우 전세가율과 갭을 추정 불가로 표기하고 필터에서 제외.
- 정규화된 계약 중 최근 전세 보증금 중앙값을 참고치로 사용하고 기준 시점과 표본 수 표시.
- 원래 d.jeon 참고치와 API 실거래치를 구분해 표시. 기존 순위 산식과 6억 이하 데이터는 변경하지 않음.
