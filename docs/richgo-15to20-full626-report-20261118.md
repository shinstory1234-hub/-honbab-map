## 작업 방법 및 단지 동일성 확인

1. `public/apt-univ20.js`에 수록된 고유 단지 626개를 추출했다. 평형별 고정순위 1,000개가 표시하는 고유 단지는 554개로 확인되며, 순위표에 나오지 않는 원자료 72개도 추가했다.
2. 300개에 관한 기존 검증 파일을 보존하면서 **나머지 326개**의 리치고 지역별 목록 및 해당 단지 상세 페이지를 수집했다. 그중 247개는 단지 이름·법정동·입주 연도·세대수로 연결했다.
3. 남은 79개는 리치고 상세 페이지에 공개된 위치 좌표를 아파트맵 대표 좌표와 대조했다. 69개는 이 방식으로 연결했고 10개는 이름과 주소, 통합단지 여부, 기존 건축물대장 정보까지 개별 대조해 연결했다.
4. 일부 **동일 단지가 아파트맵에서는 여러 블록으로 구분되고 리치고에서는 하나의 단지로 집계**된다. 이런 경우 용적률은 검증된 통합단지값을 적용했으나, 세대수를 여러 블록에 무분별하게 중복 적용하지 않았다.
5. 더샵둔촌포레, 송파더플래티넘처럼 리모델링 전후로 리치고의 입주 연도 표시와 아파트맵의 원래 연도가 크게 다른 경우, 확인된 용적률은 반영하고 연도는 원본을 유지했다. 모든 예외는 행별 조사표에 기록했다.
6. 기존 국토교통부 실거래가 기반 가격과 리치고 모델 시세는 산정 방식이 다르므로, 실제 거래 검증 근거 없이 가격을 일괄 덮어쓰지 않았다.
