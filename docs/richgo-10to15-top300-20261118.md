# 아파트맵 10억~15억 구간 상위 300개 리치고 원자료 검증 (2026-11-18)

## 적용 범위 및 결과

- 별도 브랜치: `audit/richgo-10to15-top300-20261118`. **운영 배포 또는 다른 가격대 반영 없음.**
- 대상: `public/apt-snap15-2026-11-03-m2.json`의 점수순 행을 **단지명+지역으로 중복 제거한 상위 300개 단지**. 저장된 마지막 순위 스냅샷은 2026-11-03로, 2026-11-18 현재 실시간 순위와 동일하다고 보장하지 않는다.
- 검증 처리 결과: **8개 신규 공개 페이지 직접 조회, 1개 기존 6억 이하 직접 검증 재활용, 14개 과거 252개 대조 확정값 재검증** = 총 23개 단지에 검증 근거 존재. 이 중 **용적률 8곳 변경**.
- 집계단위 불일치 5곳과 과거 일치 미검증 15곳은 원문 수치와 이유만 기록하고 자동 적용하지 않는다. 리치고 정보를 확인하지 못한 257곳은 **미조사로 명시**한다. 전체 300곳을 완료했다고 주장하지 않는다.
- 기존 시세는 실거래 중위/보정값이며 리치고의 시세 추정값과 집계방법이 다르므로 변경하지 않는다. 준공연도·세대수가 동일한 단지는 수정 필요가 없었으며, 층수·주차대수·건폐율·난방은 증빙 보존 목적으로 CSV에 기록하되 아직 렌더링 연결하지 않았다.
- 10~15억 탭 전용 `public/apt-richgo15.js`가 `apt-far-normalize.js` 뒤에서 덮어쓴다. `CAPT===15` 조건으로 6억 이하와 6~10억, 15억 초과 가격대의 데이터 변경을 방지한다.
