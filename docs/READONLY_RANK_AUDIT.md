# 아파트맵 읽기 전용 자동 검증 (격리 브랜치)

## 목적
운영 코드와 순위 산식을 전혀 변경하지 않고 **6억 이하, 6~10억, 10~15억, 15~20억, 20~25억, 25~30억** 전체 후보의 계산값을 검사한다. 이전 순위 대비 급락, 통합재건축 추진 정보와 '재건축 어려움' 라벨의 충돌, 노후 구축 상품성 처리, 가격 신뢰도 감점을 일괄 보고한다.

## 실행
```bash
node scripts/test-apt-ranks-audit.mjs
node scripts/audit-apt-ranks.mjs --out /tmp/apt-rank-audit.json
# 기존 코드와 변경 중인 코드를 각각 별도 경로에 받아놓은 경우:
node scripts/audit-apt-ranks.mjs --baseline-root /tmp/aptmap-before --out /tmp/apt-rank-diff.json
```

실제 순위 계산에는 `scripts/transport-runtime.mjs`과 운영의 최신 `apt-live.js`, `apt-geo.js` 등 필수 입력이 필요하다. 저장소에 없는 입력은 기존 실행 환경에서 제공해야 한다. **입력이 없으면 결과를 통과로 표시하지 않고 INCOMPLETE로 보고한다.**

## 검사 결과 해석
- `error`: 가격대 범위 일탈, 중복 평형, 잘못된 점수, 이전 대비 6억 이하 보호 순위 변경 등 계산 검증 실패.
- `review`: 순위 250계단 이상 하락, 상위 100위→300위 밖 이탈, 통합재건축 추진 정보와 '재건축 어려움' 표시 충돌, 거래수 부족에 따른 큰 가격 신뢰도 감점.
- `audited`: 해당 가격대 후보 전부 읽음. 사람의 판단 없이 모든 단지의 투자 가치를 검증했다는 뜻은 아님.
- `blocked`: 필수 데이터가 빠졌거나 순위 실행에 실패함. 성공으로 간주 금지.

재건축 검사는 `public/apt-data.js`의 편집 정보와 실시간 계산 결과를 **참고 수준에서 연결**한다. 이 데이터에는 동명이인 단지, 오래된 추진 정보, 아직 입력하지 않은 단지가 있을 수 있다. 검출되지 않았다는 사실은 공식 정비 현황의 완전 검증을 의미하지 않는다. 이후 별도 공식 정비구역 자료를 확보해 모든 단지에 확대해야 한다.

## 배포 안전
- 이 브랜치의 신규 파일: `scripts/audit-apt-ranks.mjs`, `scripts/test-apt-ranks-audit.mjs`, 이 문서뿐.
- 기존 `master`, 6억 이하 산식, 6억 초과 산식, 순위 CSV, DB, 운영 사이트, 배포 설정은 변경하지 않는다.
- 변경 중인 `master`의 최근 코드를 병합하지 않는 한 점검 결과는 브랜치 생성 시점의 코드에 한정된다.
- 기존 작업이 완료된 뒤 최신 코드를 별도 작업 공간에 가져와 같은 입력으로 다시 검증하고, 발견된 이상치를 별도 보고한 후에만 산식 수정 검토.

## 현재 단계
읽기 전용 검사 스크립트와 재현 테스트를 추가했다. 한가람한양 사례에서 순위 급락, 사업 단계와 추정 사업성 표현 충돌, 연식 점수, 거래 희소성 감점 네 가지 의심 신호가 감지되는 로직을 확인했다. **실제 운영 전체 단지 재검증은 아직 실행한 것으로 주장하지 않는다.**
