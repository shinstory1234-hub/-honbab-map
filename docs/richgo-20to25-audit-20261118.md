## 수집·매칭 방식

- `docs/richgo-20to25-top300-20261114-snapshot.csv`: 300개 고유 단지·가격·최초 순위 스냅샷.
- `scripts/richgo-cap25-batch.mjs`: 25개 지역의 리치고 공개 아파트 목록과 개별 상세페이지를 **동시에 최대 5개씩** 확인. 250개 지역·조건 목록과 354개 개별 상세페이지 조회 중 동일 단지 병합 및 명칭 차이를 검증하여 300개 순위 항목에 출처 연결.
- 매칭 검증: 단지명 표준화, **지역 법정동**, 준공연도, 세대수, 통합 아파트 명칭. 이름만 유사하거나 법정동이 다르면 자동 채택하지 않는다. 리치고에서 행정동별로 묶은 단지는 통합 세대수와 개별 단지 세대수를 구별한다.
- `docs/richgo-20to25-top300-audit-20261118.csv`: **300개 전 행** 기존 연도·세대수·용적률과 리치고 숫자, 출처 URL, 층수·난방·주차·시공사·건폐율·평형을 기록한 비교 결과.
- `docs/richgo-20to25-top300-audit-20261118.json`: 300개 전체의 출처, 매칭 점수, 원자료를 포함한 감사 기록.
- `docs/richgo-cap25-lookup-diagnostics.json`: 검증·누락·불일치 총계.
- 리치고의 시세는 추정 매매 시세이고 아파트맵의 시세는 실거래 기준이므로 단순 숫자 차이만으로 실거래·평형별 매매금액을 바꾸지 않았다.

**단지 통합 주의**: 옥수파크힐스 101~116동, 117~125동(30·83위), 상록마을 라이프1차(265위)는 리치고가 통합 관리단지로 표시한다. 리치고 전체 세대수를 해당 블록의 세대수로 덮어쓰면 오류이므로 **기존 블록별 세대수는 보존**, 검증된 용적률을 반영했다. 다만 푸른마을(신성)은 기존 아파트맵의 통합 2,598세대와 리치고 통합 2,598세대가 정확하게 일치한다.

**순위 기준 미충족 단지**: 대림e-편한세상4(138위)는 리치고에서 204세대로 확인돼, 아파트맵 300세대 이상 추천 정책에 따라 이 가격대의 순위에서만 제외하도록 처리했다.

## 별도 브랜치 코드 적용

- `public/apt-richgo25.js`: **상위 300건의 용적률 207건·세대수 36건·연식 20건** 불일치와 앞서 확인한 18단지를 빠짐없이 반영한 무손실 해시 기반 압축 오버레이. 가격대 25 이외에는 절대 적용되지 않는다.
- `scripts/build-apt-assets.mjs`: **20~25억 탭 전용 빌드(CAPT=25)**에서만 기존 `apt-far-normalize.js` 이후 같은 자산 청크에 리치고 보정값을 합친다. 별도 요청이나 추가 로더를 만들지 않는다.
- `public/apt-invest25.js`: 1,205개 단지 학군 자료에서 반복되는 학교 436개 정보 묶음을 공통 인덱스로 무손실 압축한다. 사전·사후 전 레코드의 값이 동일함을 검증했다.
- `public/apt-map.html`: 다른 6개 가격대 및 운영 `master`의 로더와 첫 페이지 문구를 변경하지 않았다.
- `scripts/test-richgo-20to25-verified.cjs`: 기존 18개 보정 사례, 리치고 출처, 타 구간 보존 검사.
- `scripts/test-richgo-cap25-300.cjs`: 새 300개 전 행 원자료 값, 평형·가격 불변, 타 구간 소스 및 용적률 불변 회귀검사.
- `.github/workflows/richgo-cap25-gate.yml`: 데이터 비교 테스트 및 기존 `npm run build` 용량·속도 상한 검사.

별도 브랜치에 조사 자료와 보정 코드를 저장했으며 **운영 master 병합·운영 배포는 실시하지 않았다**. GitHub Actions 테스트 및 빌드 결과는 해당 워크플로 실행 기록에서 확인한다.
