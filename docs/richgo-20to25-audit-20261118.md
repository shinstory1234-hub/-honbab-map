# 아파트맵 20억~25억 리치고 원자료 비교 (2026-11-18, 부분 완료)

## 상태 및 조사 범위
- 작업 브랜치: `audit/richgo-20to25-top300-20261118` (운영 master·다른 가격대 브랜치 미변경).
- 요청 범위: **현재 사이트의 20억 초과~25억 이하 실제 순위 상위 300개 단지**.
- 현재 **상위 300개 전수조사 완료가 아님**. 상위 300개 명단 추출에 필요한 `realestate-media.vercel.app/api/backtest/aptlive` 호출이 **HTTP 503 / `last sale lookup failed`**를 돌려주었고, `aptmap-kr.vercel.app/api/apt-first?cap=25`는 200이지만 빈 응답을 돌려주었다. 따라서 동적 현재순위를 확정할 수 없다.
- 차선으로 GitHub master의 원시 정적 단지 파일 `apt-univ10/15/20/30/univadd.js` 전체를 해석했다. 20억 초과~25억 이하 *정적 가격을 갖는* **고유 174개 단지, 평형별 289개**를 추렸다. `docs/richgo-20to25-candidate-snapshot-20261118.csv`의 첫 열은 **원본 배열 순서이며 순위가 아니다**. 실시간 시세 재배치·필터·순위 계산 전 데이터로, 300위 명단과 동일하지 않다.
- 본 조사에서 리치고 공개 단지 상세페이지 직접 확인 **7개**: 용적률 직접확인 6개, 리치고에도 용적률 공란 1개. 연식·세대수·단지 식별도 확인. 그중 아파트맵의 기존 최종 용적률 숫자와 다른 사례는 **0개**이며, 두 단지 세대수가 1,344로 각각 중복 기재된 **명백한 오류 2개를 수정**. 용적률 6개는 리치고 직접검증 출처로 표기함. *숫자가 다르지 않은 것을 정정이라고 계산하지 않는다.*
- 페이지 본문이 명시하는 리치고 시세의 기준은 2026년 8월 10일이다. 아파트맵의 최근 실거래 중위가격과 산식이 달라 시세 차이만으로 거래 원본을 변경하지 않았다.

## 적용 및 회귀 통제
- `public/apt-richgo25.js`: **CAPT===25** 전용, 공개 원문에서 식별이 확인된 경우만 처리. `apt-far-normalize.js` 이후 로드해 리치고 직접검증 용적률을 최종 적용. 수정된 극동 1·2차 세대수는 `PICKS`와 `UNITFIX_M3`에 모두 적용해 `fixUnits()` 이후 재덮어쓰기 방지.
- `public/apt-map.html`: cap25에만 추가 스크립트를 로드하도록 조건부 등록. 6억 이하 등 다른 가격대의 스크립트 목록은 그대로. 실거래 가격과 평형 자료 보존.
- `scripts/test-richgo-20to25-verified.cjs`: 직접검증 6개 용적률, 광장 극동 2개 세대수, 가격 보존, 타 가격대 미변경 검사.
- 웹 운영본에 병합하거나 배포하지 않았음. **실제 사이트의 상위 300개 선정과 300개 직접검증은 미완료**.

## 남은 핵심 작업
1. 상위 300개 실제 순위 목록을 가격 API 정상화 후 추출하고 고유 단지와 평형별 행을 명확히 구별.
2. 남은 단지별 리치고 공개 상세의 연식·세대수·용적률·층수·난방·평형 등 직접 대조 후 출처 URL 및 변경 전후 수치 기록.
3. 용적률이 리치고에도 공란인 극동2·수정 등은 **없는 숫자를 임의 생성하지 않음**. 확인된 수치만 가격대 전용 오버레이에 기록.
4. `npm run build`, 성능 예산 테스트, 상위 순위 변화 검증 후 별도 브랜치에만 반영하며 마스터 병합은 따로 결정.
