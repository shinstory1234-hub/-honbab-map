# 6억 초과 아파트맵 용적률 미확인 303곳: 단지정보 웹 대조 (2026-11-16)

## 결과
- 기존 미확인 303개 레코드 중 **15개 레코드**, 실질적으로 **13개 고유 KB 단지**의 기존 용적률을 추가 확인했다. 이는 기존 결측 85곳에 포함된 레코드다.
- KB부동산 공개 단지정보에서 기존 용적률, 주소 동명, 실제 세대수, 사용승인연도를 대조한 결과다. **건축물대장 공식 원본 검증으로 분류하지 않는다.**
- 네이버 부동산 비공식 API는 본 검증 환경에서 접속되지 않았고 검색 포털은 대량 조회 시 403을 반환해 자동 전수 검색을 완료하지 못했다. 따라서 **나머지 288곳은 미확인 상태**이지, 용적률이 없다고 확정된 것이 아니다.
- 원본 303곳: [대상 명단](apt-far-unresolved-303-2026-11-16.csv). 이 문서는 조사 증빙이며 **운영 점수/순위 데이터에 자동 적용되지 않는다.**

## 보류해야 하는 주요 데이터 품질 문제

- **여의도 시범:** 서울시의회 2020.3.6. 검토보고서에 `현황용적률 172.2%, 1,584세대`로 명시되어 있다. 그러나 현 아파트맵 `시범|서울 영등포구 여의도동`의 세대수는 **1,812세대**로 불일치한다. 데이터 식별/단지 집계 검증 전 자동 적용하지 않는다. [서울시의회 공식 자료](https://ms.smc.seoul.kr/attach/record/SEOUL/appendix/a10/A0048145.pdf?time=20260502072531).
- **잠실 우성:** 아파트맵 `우성아파트|서울 송파구 잠실동`은 **1,512세대**지만 KB의 잠실우성1·2·3차는 **1,842세대**이다. 동일 단지 여부와 집계 범위를 먼저 검증해야 한다. [서울특별시 공동주택 통합정보](https://openapt.seoul.go.kr/commonPortal/programLink.do?aptCode=A13822702&codParams=&jspNm=%2FopenApt%2FdMenu%2FdangiInfo%2FdangiInfo.open&tr_code=sweb).
- **KB에서도 현황 용적률이 빈 값인 사례:** 방배신삼호(481세대), 여의도 삼익(360세대), 여의도 은하(360세대), 개포주공6단지(1,060세대), 개포주공7단지(900세대). 값 `0` 또는 `-%`는 실제 용적률 0%를 뜻하지 않는다.
- 건축물대장 자동 조회 결과가 0이라고 인근 단지 용적률을 붙이거나, 재건축 **계획 용적률**을 **기존 용적률**로 오인해서는 안 된다.
