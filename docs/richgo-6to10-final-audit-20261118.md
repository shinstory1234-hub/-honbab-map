# 6억~10억원 리치고 전체 1,822개 단지 전수 대조 최종 보고

기준일: 2026-11-18. 별도 브랜치 `audit/richgo-6to10-top300-20261118` 기준. **운영 배포하지 않음.**

## 최종 결과
- 조사 대상: **1,822개**. 원래 1,108개 신규 공개페이지 크롤링과 기존 대조 기록을 합친 전수조사
- 공개 리치고 단지명, 행정동, 좌표 및 상세페이지로 출처 연결 성공: **1,781개**
- 리치고 대응 단지 확정 실패: **41개**. 근거가 불명확한 다른 아파트의 수치를 복사하지 않음
- 최종 6~10억원 보정 기록: **1,635건**
- 용적률 수치 확인: **1,748개**, 용적률 공란: **74개**
- 237개 보류 단지에 대한 공개 리치고 법정동 목록 전수 재탐색을 완료했으며, 187개를 우선 적용하고 9개를 추가 수동 출처 검증해 이번 단계 **196개** 새 연결
- 사용자의 데이터 출처 기준에 따라 **리치고에서 동일 단지를 확인한 경우 기존 아파트맵 세대수와 준공연도가 달라도 리치고 값으로 교체**. 용적률이 리치고에서 비어 있으면 기존 미검증 값을 리치고 검증으로 오인하지 않도록 공란 처리
- 과거 그룹단지 이름과 리치고 단지 구분이 다른 사례가 남아 있으므로, 41개 미연결까지 완전 검증됐다는 뜻은 아님
