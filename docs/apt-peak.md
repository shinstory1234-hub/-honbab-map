# 전고점 돌파 가점

## 계산 기준

- 고점 기간: 2021-07-01 이상, 2022-07-01 미만.
- 단지 식별: DB의 `(sgg, dong, name)`.
- 면적 구간: `round(area / 5) * 5`. 운영 `bt_aggcur.ab`와 같은 구간이다. floor를 고점에만 쓰면 현재 시세와 다른 평형을 비교하게 된다. 원본 감사에서 동답한신 44.35㎡가 현재 ab45, 공작부영 37.85㎡가 ab40인 것을 확인했다.
- 해제 거래(`canceled=true`)와 0 이하 금액을 제외하고 각 구간의 높은 거래 3건을 고른다. 2건이면 2건 평균, 1건 이하면 제외한다.
- 구간 비율 `r_i = bt_aggcur.cur / 고점 평균`, 단지 비율 `r = sum(n_i * r_i) / sum(n_i)`. 비교 가능한 구간의 `n`만 분모에 포함한다. 현재 테이블에 같은 구간의 서로 다른 건축연도 행이 있으면 각 행의 거래수로 가중한다.
- 현재 가격은 원래 요청한 `bt_aggcur.cur`를 사용한다. 최근 3개월 중위 또는 표본 부족 시 지수 환산 시세이며, 단일 최고 실거래나 호가로 대체하지 않는다.
- 단지명이 같더라도 시군구가 다르면 합치지 않는다. `단지명|동` 키가 여러 시군구에 겹치면 출력에서 제외한다.

DB가 각 구간을 필터·금액 내림차순 정렬해 상위 3건을 반환하고 서버가 평균·비율을 계산한다. 생성 스크립트가 단지별 거래수 가중평균을 계산한다. 직접 SQL 실행은 하지 않았으며, 동등한 조회식은 `scripts/apt-peak.sql`에 기록했다. DB 가격·원본 거래는 변경하지 않는다.

## 가점과 표시

`public/apt-peak.js`에는 r≥0.95인 단지만 소수 6자리로 저장한다. 비율이 있어도 **r≤1이면 가점은 0**이다. 전고점을 넘은 단지에만 가점을 적용한다.

```
bonus = 10 * clamp01((r - 1.00) / 0.10)
comp = 기존 종합 점수 + bonus
```

100% 초과부터 110%까지 선형 증가하고 이후 최대 10점으로 제한한다. 최대 가점은 판단값이며 미래 상승률에 대한 검증 결과가 아니다. 가격이 이미 높은 단지에 유리한 지표이고, 고점 기간에 거래가 없었던 신축은 가점이 없다. 순위 비중 민감도(`apt-band.js`)에도 같은 가점을 더한다.

상세 '순위 근거'에 비율을 표시하고 실제 가점이 있을 때만 점수도 표시한다. 종합 점수 설명에 가점을 포함하며 과거 기본 모델의 검증 성과와 구분한다.

`관양동 공작부영|관양동`은 DB의 `공작아파트|관양동`에 연결하는 명시적 별칭이다. 운영 감사에서 1993년 입주, 소형 현재 시세 51,000만원, 거래수 102건이 사이트와 일치하는 것을 확인했다. 같은 동의 공작럭키·공작성일과 혼동하지 않는다. 임의 유사 이름 매칭은 하지 않는다.

## 재생성

서버 `/api/backtest/collect?mode=status`와 `mode=peak&basis=round&offset=...`는 수집기 토큰이 필요하다. 토큰 값은 인자·출력·소스에 넣지 않는다. 파일 경로만 인자로 전달한다.

```bash
cd /workspace/-honbab-map
python scripts/export-apt-peak.py /secure/path/to/token /workspace/shared/apt-peak-evidence.json
node scripts/build-apt-peak.mjs /workspace/shared/apt-peak-evidence.json
node scripts/test-apt-peak.mjs
node scripts/test-apt-peak-build.mjs
npm run build
```

내보내기는 924개 작업 전부 done이고 err=0일 때만 가능하다. 생성기는 모든 현재 행의 페이지가 빠짐없이 있는지, 반올림 기준인지, 거래수가 양수인지, 평균 대비 비율이 일치하는지 검사한다. 원본 근거 파일은 저장소 밖에 두고 SHA-256 및 집계 수치를 `scripts/apt-peak-metadata.json`에 남긴다.

운영과 같은 순위 검증에는 `https://realestate-media.vercel.app/api/backtest/aptgeo?export=js`를 받아 `/apt-geo.js`로 함께 서빙해야 한다. 이 파일을 저장소에 추가하지 않는다. 파일이 없는 단순 로컬 HTML 실행은 대표 순위를 검증하지 못한다.

## 검증 결과 (2026-10-26)

- 수집 924/924 done, todo=0, err=0, 저장 121,560건(해제 여부는 고점 계산 시 제외).
- 현재 27,293행 전부 조회, 고점 근거가 있는 13,977행·13,968개 면적구간·8,228개 단지. r≥0.95인 3,458개 단지와 표시명 별칭 1개를 공개 데이터에 저장했다.
- 운영 위치 파일 331개 키를 함께 서빙한 headless Chromium에서 데스크톱·모바일 모두 5,871개 평형, 비정상 점수 0, 페이지 오류 0. 모든 평형의 점수가 `기존 점수 + 가점`과 일치하고 r≤1에 가점이 붙은 경우는 0이었다.
