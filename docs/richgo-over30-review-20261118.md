## 범위와 검증 현황

- 대상: 아파트맵의 `?cap=35`(30억 이상). 6억 이하부터 25~30억까지의 다른 가격대 코드를 수정하지 않음.
- 원래 목표: **현행 종합순위 상위 300개**. 현재 서버에서 실거래 자료를 불러와 순위를 동적으로 산정하므로, 이 문서에 있는 19개를 **상위 1~19위 또는 상위 300위의 일부라고 단정하지 않음**.
- 진행: 개별 공개 단지정보 21개 검토. 그중 단지 동일성을 확인한 19개를 보정 목록으로 등록. **300개 전수 완료 아님**.
- 검증 항목: 단지명, 법정동, 세대수, 입주연도, 용적률. 실거래 시세는 아파트맵의 국토부 기반 원자료를 그대로 둠(리치고 추정 시세와 산출기준 불일치).
- 저장: `docs/richgo-over30-audit-20261118.csv`에 아파트맵 고가 단지 유니버스 최초 메타데이터, 리치고 단지정보, 개별 단지 주소, 대조 결과 기록.

## 반영 방식과 격리

- `public/apt-richgo35-corrections.js`: `CAPT===35`에서만 실행, 단지명·법정동·세대수 일치 검증, 단지별 근거 URL 보관.
- `public/apt-map.html`: 공적 원자료 복원(`apt-far-normalize.js`) **이후**에 35 전용 오버레이 실행. 다른 가격대는 스크립트 자체를 로드하지 않음.
- 기존 집계 순위 로직과 각 평형의 거래가격을 직접 수정하지 않음. **용적률과 입주연도 보정에 따라 30억 이상 구간의 점수/순위는 재계산 시 달라질 수 있음.**
- 런타임 확인: 19개 단지를 인위적으로 고가 실거래 목록에 넣어 유니버스를 생성한 모의시험에서는 19개 모두 단지정보 일치, 용적률 공란 8개 보완, 용적률 차이 6개 수정, 연도 1개 수정, 가격 변경 없음. **운영 사이트 실제 상위 300개 조회 및 완성 배포 검증을 뜻하지 않음.**
- 자동 테스트 파일: `node scripts/test-richgo-over30-audit.cjs` (테스트 실행은 별도 환경에서 필요).
