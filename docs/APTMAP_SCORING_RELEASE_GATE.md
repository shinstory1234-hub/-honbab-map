# 아파트맵 산식 변경 및 배포 필수 검증 절차

## 절대 순서
**산식 수정 → 실제 전체 순위 재계산 및 결과 확인 → 과소평가 단지와 과대평가 단지 재검토 → 이상 없을 때만 운영 배포**

모든 산식 수정에서 이 순서를 생략하지 않는다.

1. **산식 수정(독립 브랜치)**: 정책 목표, 변경 대상 가격대, 불변 가격대를 먼저 확정한다. 이전 산식을 저장한 상태로 수정한다.
2. **결과 확인(전체 후보 검증)**: 서울·경기·인천 대상 가격대 전체 평형을 새 산식과 기존 산식으로 동시에 계산한다. 가격, 점수, 전체 순위, 상위 10·30·100위, 지역별 구성, 대표 평형 변경을 비교한다. 화면 렌더링과 검색, 가격 검증 경고도 확인한다.
3. **양방향 이상치 검토**: (가) 분명히 좋은 단지가 정당한 근거 없이 아래로 밀려나는지, (나) 시세가 오래됐거나 극소수 거래만 있는 단지가 저렴한 가격 때문에 비정상적으로 위로 튀는지 각각 조사한다. 상위권 진입, 30위·100위 이상 급변, 같은 단지의 작은 평형이 크고 더 저렴한 평형을 제치는 경우를 모두 점검한다. 가격 신뢰도와 단지 품질을 구분하고, 정보 부족을 검증된 저평가로 오인하지 않는다.
4. **이상 징후를 즉시 사용자에게 알림**: 래미안에스티움과 신길파크자이처럼 일반적 주거 선호나 객관적 조건에 배치되는 결과가 나오면 어떤 산식 변화 때문인지, 변경 전후 점수와 순위를 함께 보고한다. 사용자가 지적하기를 기다리지 않는다. 설명할 수 없는 역전은 수정 없이 통과시키지 않는다.
5. **배포 전 최종 확인**: 보호 가격대 순위, 대표 단지 비교, 정상 브라우저 작동, 전체 결과의 예상 변화 범위 및 고위험 가격 경고를 확인한다. 신규 이상치는 해결 또는 별도 명시하고 판단받은 후 배포한다. 배포 뒤 운영 사이트에서 다시 검증한다.

## 고정 검증 대조군
- **10~15억원**: 센트라스 16평과 목동센트럴아이파크위브3단지 24평의 입지·교통·면적 및 시세 신뢰도 차이를 확인한다. 변경 전후 역전이 발생하면 가격과 단지 경쟁력 근거를 밝히고 설명 불가능할 때 배포하지 않는다.
- **15~20억원**: 래미안에스티움 24평과 신길파크자이 34평의 순위 역전 및 원인을 항상 확인한다.
- **6~10억원**: 과거 단일 거래가격만으로 상위권에 올라갔던 후보가 재진입하지 않았는지 확인한다.
- **10~15억원**: DMC아트포레자이 30평의 시세 검증 보류를 무단 해제하지 않는다.
- **25~30억원**: 개포·잠실 단지 상위권의 큰 순위 변동, 디에이치아너힐즈 급락, 과천 단지의 지나친 고평가를 함께 검토한다.
- **6억원 이하**: 사용자가 변경을 요청하지 않는 한 기존 평가 산식과 순위가 바뀌지 않아야 한다.

## 결과 보고 형식
- 변경 대상과 목적.
- 전체 후보 수, 기존 대비 상위 30위 신규 진입·이탈, 최대 순위 상승·하락 사례.
- 과소평가·과대평가 의심 단지 각각의 근거와 처리 여부.
- 최신 실거래 기준일과 아직 검증하지 못한 데이터의 범위.
- 배포 여부, 실제 운영 페이지에서 검증한 항목.

## 공개 UI 품질 검증
- **시가 6억 이상**: 개인 대출 심사 없이 산출한 '생애최초 대출 시'나 주택담보대출 가능 금액, 단순 자금 섹션을 표시하지 않는다.
- **전 가격대**: 신축·학군·대단지·브랜드·역세권·초등학교 접근성 등 단지별 독립 평가 점수는 상세 화면에서 제공한다. 실제로 반영하지 않는 항목을 종합점수의 가산점이라고 주장하지 않는다.
- 모델 가중치, 세부 보정식, 회귀식과 가격 추정 절차는 공개 상세 화면에서 제외한다. 공개 점수와 세부 비공개 산식을 명확히 구분한다.

## K-apt 통합 단지와 구분 블록의 평가 원칙

- **하나의 공식 통합 관리단지**로 확인되면 투자 추천의 단지는 하나로 취급한다. 목동센트럴아이파크위브 1~4단지의 공식 총 세대수는 3,045세대이며, 분리 블록 592·962·574·917세대는 이 합계와 정확히 일치함을 검증하는 용도다.
- 평형별 시세와 계약 표본은 **개별 거래 원본대로 보존**한다. 목록의 단지 순위는 하나, 상세 화면에는 1~4단지의 가격대별 실제 평형을 모두 노출한다.
- 통합 단지의 입지·교통·직주·연식 점수는 확인된 구분 블록의 세대수 가중 평균으로 평가한다. 교통이 유리한 3단지 하나를 전체 단지의 대표 교통 점수로 삼지 않는다.
- **10~15억의 검증된 통합단지에 한해** 기존 S4 장기 급지 게이트를 K-apt 통합 대단지 가점에 반영한다. 신축 자체의 품질 점수는 강제 감점하지 않는다. 일반 단지까지 급지 게이트를 일괄 적용하는 시험은 녹번역e편한세상캐슬(65→377위), 산성역포레스티아(22→285위) 등 과도한 순위 급락이 확인돼 철회했다. 다른 가격대의 기존 평가 비중은 유지한다.
- 동일 지역 및 이름의 `N단지` 패턴이라고 모두 통합하지 않는다. 공식 동일 총세대수가 부여되어 있고 구분 블록 원본 세대수 합계가 공식 총세대수와 정확히 일치하는 그룹만 통합한다. 합계가 맞지 않는 그룹은 원본 그대로 유지한다.
- 배포 시 반드시 6개 가격대 전체 순위와 가격, 두 방향의 상위권 이상치, 검색 결과, 지도 중복 핀, 세부 평형 노출을 테스트한다.
- 회귀 테스트: `node scripts/test-kapt-group-split.cjs`, `node scripts/test-m3-price-policy.cjs`.
