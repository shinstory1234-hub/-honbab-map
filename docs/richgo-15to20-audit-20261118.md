## 실제 코드 변경 및 배포 격리

1. `public/apt-univ20.js`: 실제 미적용 상태였던 용적률 6곳을 리치고 값으로 고쳤으며, 가락1차쌍용아파트 세대수 1곳을 2,064로 보정했다. 이는 **15~20억 원자료 파일**이며 `apt-univ10.js`, `apt-univ15.js`, `apt-univ30.js`는 수정하지 않았다.
2. `public/apt-far-normalize.js`: 불필요한 런타임 중복 교정 로직을 최종 제거했다. 실제 원본 6건을 수정하고 이미 검증된 21건을 다시 덮어쓰지 않아 전송량을 줄였다.
3. `scripts/test-richgo20-top300.cjs`: 300개 대상 목록, 검증 상태, 소스 정합성과 최종 용적률을 확인한다.
4. `.github/workflows/richgo20-audit-validation.yml`: 브랜치별 회귀 검사와 정적 빌드·전송량 예산 검사를 실행한다.
5. **운영 `master`에는 병합하지 않았다**. 새로운 분기 데이터 역시 전체 고가 탭 공통 데이터 묶음에 읽혀질 수 있으나 기존 다른 가격대 원자료 파일을 직접 수정하지 않았다.

## 미완료 작업과 주의

- 나머지 273곳의 리치고 기본 정보 **직접 검증이 완료되지 않았다**. 전수조사 완료·전체 오류 수정 완료로 표시할 수 없다.
- 가격은 아파트맵의 최근 실거래 기반 대표가격과 리치고 추정 시세가 산식이 달라 함부로 덮어쓰지 않았다. 학군·교통·주차·건폐율·좌표·세부 평형별 시세·거래내역 등 다른 원자료 항목은 300곳 전수 대조하지 못했다.
- 특히 단지 합계 세대수와 일반분양 세대수 차이는 데이터 오류가 아닐 수 있어 비율과 집계범위 확인이 필요하다.
- 리치고 공개 API는 별도 키와 계약이 필요하며, 제공자 약관에는 원자료의 웹사이트·DB·저장소 재배포 금지 및 상업적 활용 제한이 있다. 대량 자동 대조를 운영할 때는 데이터 이용 권한을 별도로 확인해야 한다. 참고: https://m.richgo.ai/developers
