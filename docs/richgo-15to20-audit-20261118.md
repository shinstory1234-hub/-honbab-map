# 15억 초과~20억 이하, 아파트맵 상위 300개 고유 단지 리치고 대조

작성: 2026-11-18 / 작업 브랜치: `audit/richgo-15to20-top300-20261118`

## 결과와 범위

- 15~20억 탭의 기존 `public/apt-invest20.js` 고정순위에서 처음 등장하는 고유 단지 300곳을 뽑았다. 이들은 **평형별 1~572위**에 대응한다. 한 단지에 복수 평형이 있더라도 1곳으로 센다.
- 300곳의 아파트맵 원자료는 `public/apt-univ20.js`와 매칭하여 목록으로 저장했다. 300곳의 **리치고 전수 확인을 완료한 것은 아니다.**
- 리치고 직접 확인(2026-11-18): **10곳**.
- 기존 2026-11-16 리치고 교차확인 결과에서 동일 단지로 확정된 값을 재사용: **14곳**. 금일 재방문 검증은 하지 않았다.
- 아직 미완료: **276곳**(이전 검증 후보가 있었지만 동일성이 불확실한 23곳 포함).
- 이 300곳의 `apt-univ20.js` 기본 용적률 공란: **165곳**. 추정치·기존 보정값을 구분해야 하며, 실제 서비스에서 모든 165곳이 미표시라는 뜻은 아니다.
- 확정 24곳 중 `apt-univ20.js`의 *기본* 용적률과 리치고가 다른 곳: **23곳**. `apt-farfix.js` 등 기존 보정값까지 반영한 최종 차이 건수와는 다르다.
- 리치고가 다른 세대수를 명시한 3곳은 해당 탭 한정으로 세대수도 교정했다. 연도 차이는 확인한 10곳에서 없었다.

## 데이터 적용

- **15~20억 탭에서만** 고유 단지 키 `단지명|지역`을 기준으로 확정 24곳의 기존 용적률을 리치고 값으로 대체한다.
- 2026-11-18 직접 확인한 10곳의 입주 연도와 세대수를 비교하여 서로 다르면 해당 탭의 `PICKS` 및 `UNITFIX`에 반영한다. 기존 2026-11-16 확정 14곳은 세대수 변경 근거를 이번 CSV에 별도로 갖고 있지 않아 용적률만 교체한다.
- **6억 이하부터 15억 이하, 20억 초과 탭 모두 미변경.** 빌드에서 전송되는 데이터 크기 제한을 올리거나 우회하지 않는다.
- 가격은 아파트맵의 최근 실거래 기반 중위가격과 리치고의 추정 시세가 달라 임의로 교체하지 않는다.
- 단지명·주소·세대수가 상충하거나 후보가 없는 276곳의 미확인 수치는 자동 채택하지 않는다. `미조회`, `검증보류`를 정확하게 기록했다.
