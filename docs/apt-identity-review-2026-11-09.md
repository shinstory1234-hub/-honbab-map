# 단지 식별키 연결 수정 검증

기준 커밋: `63ec3377c47d4ff3b5144443ddb5c4b59a9bd25c`. 시세 입력은 기존 `apt-live.js`의 2026-11-03 자료이며, 이번 변경에서 새로 수집하지 않았다.

## 문제와 변경

표시 이름에 `(고층)`이 없는 네 단지가 원자료와 연결되지 않아 예전 시세와 동 단위 급지를 사용했다. 기존 평형별 거래 건수는 원자료의 고층 구분과 일치한다. 이 확인된 대응만 `aptSourceKey`에 등록하고 시세, 주변 단지 급지 평활, 급지 백분위 기준표, 최종 급지 조회에서 공통으로 사용한다.

| 화면 이름 | 원자료 식별키 | 기존 평형별 거래 건수 대조 |
| --- | --- | --- |
| 상계주공14 | 11350\|상계동\|상계주공14(고층) | 20평 44건, 24평 10건, 36평 5건 |
| 상계주공10 | 11350\|상계동\|상계주공10(고층) | 20평 25건, 24평 39건, 26평 5건, 28평 6건 |
| 상계주공2 | 11350\|상계동\|상계주공2(고층) | 24평 49건, 28평 14건 |
| 하안 주공8 | 41210\|하안동\|주공8(고층) | 18평 29건, 24평 65건, 32평 8건 |

저층 거래는 합치지 않는다. 이름의 괄호나 번호를 일괄 제거하지 않는다. 표시 이름, 가중치, 감점 규칙, 가격 제외 규칙은 변경하지 않는다.

## 결과

동일 입력 자료와 기본 설정으로 전체 가격대의 페이지 스크립트를 실행했다. 6억 이하 5,822개 평형은 점수와 순위를 포함한 기존 결과와 정확히 일치했다.

6~10억의 24평 비교:

| 단지 | 이전 순위 | 수정 순위 | 연결된 대표가격 |
| --- | ---: | ---: | ---: |
| 상계주공14 | 5 | 293 | 69,927만원 |
| 상계주공10 | 6 | 112 | 74,000만원 |
| 상계주공2 | 7 | 10 | 73,270만원 |
| 하안 주공8 | 13 | 263 | 77,034만원 |

급지 평활과 백분위 분포, 평당가 비교 기준은 원래 자료에 따라 재계산된다. 따라서 직접 연결을 수정하지 않은 단지도 소폭 변한다. 그 점수 변화는 해당 항목의 변화로 전부 설명된다. 다른 단지의 대표가격, 교통, 밀도, 기타 감점은 유지된다.

검사: 네 파일의 문법, 동일 이름의 다른 지역 오연결 방지, 저층 오연결 방지, 시세와 급지의 동일 식별키, 거래일, 가격대 경계, 중복 평형, 점수 정렬, 재계산의 결정성, 6억 이하 결과 고정.

재현 명령: `node scripts/test-apt-identity.mjs <기준-소스-경로> <수정-소스-경로>`. 두 경로는 같은 `apt-live.js`와 `apt-geo.js`를 사용해야 한다. `transport-runtime.mjs`가 실제 페이지 스크립트를 실행한다.

이번 배포에는 가격 이상 의심 평형의 추천 제외를 포함하지 않는다. 신축의 거래 건수가 적다는 이유만으로 제외하지 않는다.
