# 아파트맵 가격 역전 37쌍 원천 데이터 검토 (2026-11-21)

## 검토 범위
- 기준: `analysis/2026-11-20/aptmap_anomaly_candidates_2026-11-20.csv`의 평형 가격 역전 37쌍(36개 단지)
- 데이터: realestate-media Supabase의 `bt_livecur`와 `bt_apt_trades` 읽기 전용 조회
- 결과: 37쌍 모두 원천 시세 DB의 양쪽 평형과 매칭(‘송내동 우성’의 원천명은 ‘우성’)
- 이 문서는 **검토 기록**이며 가격이나 순위를 수정하지 않음. 원천 DB 표본 시점과 11/20 순위 CSV는 다를 수 있음.
- 전체 각 쌍의 시세/거래건수/갱신일/거래유형 분포: `aptmap_37_price_inversions_audit.csv`

## 확인한 현상
1. **금호어울림(성남동) 30평**: 2026-03-04 6층 전용 74.48㎡ **4억 6,200만원 1건**, 원천 `deal_type=NULL`. 사용자 확인에 따르면 직거래. `bt_livecur.cur=48,510`만원으로 원천 1건의 가격×1.05에 정확히 해당하며, 34평 정상 표본 15건의 9.99억원 시세와 불일치. 현재 필터는 `deal_type='직거래'`만 제외하므로 NULL은 포함됨. *공식 원본 거래유형 재확인 전 확정 판정 아님*.
2. **송내동 우성 50평**: 원천명 `우성`, 2026-08-07 9층 전용 127.22㎡ **3억 9,040만원 직거래**가 `bt_apt_trades`에 명시. 하지만 `bt_livecur`의 50평 가격이 **3억 9,479만원**, 업데이트 11/03의 오래된 행으로 남음.
3. **엘지빌리지1 92평**: 2026-10-15 20층 전용 229.825㎡ **5억 8,000만원 직거래**가 원천 DB에 명시. `bt_livecur`의 92평 가격 **5억 9,740만원**, 업데이트 11/03의 오래된 행으로 남음.
4. **이외 일부 평형 시세 갱신 날짜 차이**: 탑마을(경남)1 46평, 영종어울림1차 42평, 장안타운(건영) 40평은 일부 표본 행이 11/03 또는 다른 날짜로 남아 원천 최신성 별도 대조가 필요.
5. 원천 수집 상태 점검 시 `bt_live_sync` 작업 **294/308 완료, 14 미완료, priced=false, complete=false**였다. 진행 중 부분 수집과 시세 게시 완료를 구분해야 함.

## 구조적 원인 및 조치안
- `realestate-media/src/lib/molit/live-prices.ts`: 계산에는 `deal_type!=='직거래'` 필터가 있으나 `NULL` 거래유형은 통과한다. 4개월보다 오래된 원천 데이터는 거래유형이 미기재된 채 남을 수 있다.
- `realestate-media/src/lib/molit/bt-live.ts`: 월별 갱신 구간이 최근 4개월(`REFRESH_MONTHS=4`)이므로 2026-03 금호 계약은 현행 갱신으로 거래유형이 정정되지 않는다.
- `realestate-media/src/lib/molit/refresh-live-prices.ts`: 정상 거래를 계산하고 `bt_livecur.upsert`만 수행. 소스에서 직거래 제외로 사라진 이전 평형의 행은 삭제되지 않음. **유효 집합과 목적지 집합의 원자적 동기화(replace/reconcile) 필요**.
- `aptmap/public/apt-livefix.js`: 일부 평형의 가격 역전을 제한적으로만 방어한다(중간 가격대, 인접 평형, 충분 거래). 6억 이하·25억 이상은 기존 값 보존. 이 로직에서 가격을 억지로 일치시키기보다 upstream 정상 거래 데이터/검증된 추정 가격을 쓰도록 변경.
- 정상 거래 표본이 사라지면 과거 시세나 단일 직거래 시세로 **조용히 되돌아가지 않도록** 검증 보류 상태를 전달해야 함.

## 안전한 실행 순서
1. **원본 정정:** 37쌍의 해당 평형·월 데이터를 공식 실거래 원본과 비교. 명시적 직거래/해제는 산정에서 제외. 미기재 표본은 근거를 찾아 교정하거나 검증 보류.
2. **가격 집계 정합성:** 전체 수집 완료 또는 명시적 버전 스냅샷 확보 후, 유효 가격 키 집합을 DB에 원자적으로 반영해 이전 잔존 행 제거. 실패하면 마지막 완전본 유지.
3. **미확인 가격 처리:** 검증 전 특정 평형의 현재 매수가격 확정·저평가 추천을 하지 않고 경고/제외. 인접 평형 환산은 어디까지나 추정값으로 표시. 충분 표본의 큰 평형 할인은 일률적 역전 금지 보정으로 덮지 않음.
4. **회귀 테스트:** 37쌍 중 미해결 유형·변경 전후 가격·순위와 전체 13,718개 평형의 가격대별 순위, 신구 시세 분포, 중복/누락 및 전송량 검증. `docs/APTMAP_SCORING_RELEASE_GATE.md`와 `AGENTS.md` 준수.
5. **배포:** 본 분석에서는 시행하지 않음. 전수 비교·성능 검증 후 변경 결과를 검토할 때 별도로 결정.

## 주의
- `bt_livecur`의 12개월 거래건수는 거래유형 NULL 표본을 포함할 수 있고, 원본 테이블 상태/갱신시점이 다르면 대조 건수가 다를 수 있음.
- 대형 평형이 저렴하다는 사실만으로 원천 거래 오류는 아님. 복층·저층·동별 차이·시기 차이로도 실제 역전은 발생할 수 있음.
- 11/20 분석 CSV의 소수점 가격과 11/21 실시간 DB 시세가 다를 수 있음. 수정 전 반드시 같은 데이터 기준일로 재현해야 함.
