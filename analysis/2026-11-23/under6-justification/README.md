## 개별 판단의 논리

1. **기존 순위가 성립할 근거**: 입지점수, 12개월·3개월 실거래 건수, 시세, 준공연도, 세대수, 면적, 기존 모형 적정가 대비 여력, 직접 위아래 순위의 다른 단지와의 비교. 같은 지역에서 연식±15년, 면적±8평과 12개월 거래 5건 이상 비교단지를 최대 2곳 선별하고 공급평당가 및 간단한 연식 보정 차이를 표시.
2. **현재 순위에 반대되는 근거**: 검증되지 않은 초소형 가격·거래 0~4건·최근 거래 없음·단지 식별 보류·고위험 가격 역전·입지나 면적 열세·주상복합 상품 특성·원 종합점수 0점의 동률. 순위가 역으로 보이는 인접 단지의 객관 지표도 기록.
3. **순위 변경 방식**: 두 가중모형(A: 가치·입지·연식·규모·면적·근접시세/위험, B: 입지·상품성과 거래 신뢰도 가중)을 다시 순위화해 위치의 민감도를 비교. 양쪽이 일관되게 위·아래를 가리킬 때만 잠정 상향·하향 권고. 모델 의견이 벌어지거나 거래 검증이 불충분하면 **정확한 새로운 순위 숫자는 제시하지 않고 유보**, 검증 후 재배치 기준을 명시.
4. **정비사업 예외 재검증**: 기존 단지가 오래됐다고 자동 감가한 모델에는 재건축·리모델링의 사업진척·대지지분·분담금 가치가 누락될 수 있음. 공고·확인 가능한 단계와 리치고 용적률·기존 정비사업 입력을 추가 대조해 관련 평형 **120개를 별도 검증으로 분류**. 단순 저용적률만으로 수익성을 확정하지 않음.
5. **연동 오해 방지**: A/B 모형 순위는 임의 가중치에 따른 참고 모형의 상대적 위치이지 법적 감정평가, 확정 매매가 또는 예상 투자수익률이 아님. 기존 `예상여력_pct`도 사이트 모형 출력이지 실현 기대수익률이라고 주장하지 않음.
