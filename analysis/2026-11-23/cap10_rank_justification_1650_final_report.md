# 6억 초과~10억 이하 1,650개 전체 단지 순위의 정당성 심사 (2026-11-23)

## 결론부터

- **기존 1,650개 순위의 그대로 유지 = 기각.** 기본 독립모형에서 기존 인접 단지 간 1.5점 이상 역전 657쌍(인접한 위치 1,649쌍 대비 39.8%).
- 기존 순위를 다른 4가지 점수 가중치의 서열과 비교하면 **상향 우세 541개, 하향 우세 614개, 기존 위치 범위 안 400개, 판단 혼재 95개**. 이들은 기존 원천자료를 공유하므로 **4개의 독립적인 외부 검증**으로 읽어서는 안 됨.
- 기존 순위에 유지 가능 판정이 있어도 **정확한 한 자리 순위가 입증된 것은 아님**. 제안된 예비종합서열의 인접단지 점수차가 0.5점 미만인 경우에 포함되는 단지는 1,365개로, 인접 순위 숫자를 구분하기 어렵다.
- **이번 작업은 원시데이터 수집보다 순위의 정당성 심사가 목표**. 따라서 모든 단지에 기존 위치의 우열 근거·장기입지/직주/교통/규모/상품성/학군/평형/상대가격 요인·가중치 시나리오 순위·기존 인접 단지와 비교·예비 서열 인근 경쟁 단지 비교·순위 유지/상향/하향/보류 근거를 기록함.
- 별도로 교차 검증된 29개 단지, 추가 거래가격 3개 단지, 주차·정비사업의 중요한 현장 사실을 종합판단 칸에 결합함. 나머지 단지들의 모든 외부 사실까지 실제로 완전 검증했다는 뜻은 아니므로 **정당성 판단은 기존 모델 입력에 조건부**임.
- **운영과 배포는 변경하지 않았고 별도 분석 브랜치에만 저장**. 매물 존재와 즉시 매수가능 여부는 어떤 순위 평가에도 사용하지 않음.

## 판정 방식

1. **기존 서열 반박 여부:** 기존 바로 위·아래 단지와 독립점수 차이를 계산하고, 위에 있는 단지보다 대상이 1.5점 이상 높거나 아래 단지가 1.5점 이상 높으면 원서열에 반증 기록.
2. **투자 이유:** 6~10억 비교군 1,650개 전체 각 평가차원 중앙값과 해당 단지의 가중점수 편차를 계산해 독보적인 강점과 지불해야 할 약점을 함께 식별. 가격상대가치 근거에는 동급 비교 수, 비교가중신뢰도, 동일 평형 거래수를 붙여 저평가와 단순 저품질을 구분.
3. **근처 경쟁자 직접 비교:** 현재 순위 인접 2개, 예비 서열 근처 상·하위 2개의 실점수·요인별 점수 차이를 개별적으로 문장화하여 어느 강점이 무엇을 상쇄하는지 기록.
4. **정확한 숫자의 강건성:** 기존 기본모형과 입지중심/가격중심/상품중심 대체 가중치 4개 순위의 중위값으로 모든 1,650개의 예비 서열을 매김. 이는 **4개 가중치모형 중위서열이지 최종 투자 추천 서열이 아니다.** 서로 같은 기초 데이터의 오류를 공유할 수 있음.
5. **증빙 부족은 유리하게 취급하지 않음:** 원시세 위험, 정비사업 단계, 낮은 주차, 거래유형 및 주택형 착오 등이 확인되면 모형 순위가 높아도 정확한 순위를 기각·보류. 주차를 검증하지 않은 다른 단지들에 일괄 무작위 감점을 부과하지는 않음.
6. **명시적 판단 단위:** 순위는 관리단지의 6~10억 대표 평형 단위, 동일 단지 타 평형의 가치·실거래가격을 혼동하면 안 됨. 장기 가격상승률을 관측/백테스트해 산정한 것이 아니며 미래 차익 확정값이 아님.

## 중요 사례: 숫자만 따라가면 잘못되는 곳

- **강동리엔파크14단지 (기존1 → 예비30):** 2021년 신축과 943세대라는 유리한 실거주 요소가 있으나, 기존 입력 교통점수 8.8과 20평의 효용이 낮아 다른 6~10억 후보와 비교하면 기존 절대 1위를 방어하기 어렵다. 다만 상품성 중심 모형에서는 4위까지 올라가므로 정확한 30위도 확정할 수 없다.
- **초원부영 (기존2 → 예비10):** 1,743세대, 평촌역, 학군과 정비계획안 공람이라는 장점은 실제다. 1992년 건축 노후화와 사업비 불확실성 때문에 현행 2위는 당연하지 않지만, 정비가치를 자동 보너스 수준으로 축소하고 10위로 확정하는 것도 부당하다. **상위권 지지, 정확한 번호 보류**.
- **하안주공10 (기존3 → 독립모형70):** 광명시 2025-12-10 정비구역·사업시행자 지정 공식사실은 가치에 영향을 준다. 기존 3위는 우열 증거 부족이지만 독립 70위도 사업비/분담금 분석 부재로 확정 불가. 해당 단지의 자세한 우위·열위는 1,650행 CSV 참조.
- **초록(화곡동) (기존15 → 예비1):** 가격 비교상 강점이 있지만 주차 0.68대라는 취약점이 모형에 충분히 반영되지 않아 **예비 1위를 최종 1위로 승인하지 않음**.
- **상계주공1(고층) (기존371 → 예비4):** 주변보다 저렴하고 모형상 입지가 유리하지만 주차 0.45대, 노후 및 정비비용을 반영하지 않은 4위는 정당화 불가능. 기존 371위가 지나치게 낮았는지는 별도 판단하되 **4위 확정 기각**.
- **거여4단지 (독립19 → 예비16):** 모델8.91억과 동일전용 최근 9.95~10.4억 거래 간 차이. 실제 유효시세가 10억 경계 밖이라면 아예 이 가격대 후보가 아니라는 점이 순위 논의보다 먼저다.
- **현대리버빌1지구 (독립29 → 예비34):** 모델 9.46억과 2026-10 거래 11.5억 신고 대조로 10억 구간 유지 및 가격논리가 불안정. 점수 1점 조정이 아니라 소속 구간부터 다시 검토해야 한다.

### 이번 심사에서 명확하게 못 한 것

- 전체 1,650개의 주차대수, 2026-11-23까지 최신 국토부 개별 거래해제/직거래, 정비사업 분담금까지 새로 모두 수집해 완전 검증하지 못함.
- 모든 단지의 공정한 정확한 1위~1650위 숫자를 '사실상 유일한 정답'으로 입증하는 것은 불가능. 새 점수 차의 다수가 작아 제안 순위 역시 평가기준에 조건부.
- 4가지 시나리오는 동일 원천 데이터의 가중치 민감도이지 독립 관측 검증 아님. **모형상 4/4 상향도 주차·가격 현실을 보면 뒤집힐 수 있음.**
