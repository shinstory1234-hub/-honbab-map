# 6억 이하 5,630개 평형 독립 정량 교차감사 (2026-11-23)

- **조사 범위:** 2026-11-20 원본 전체 5,630개 평형, 2,574개 단지. 기존 6개 순위 파일 5,630행과 식별키·순위·가격·12개월 거래수를 일대일 대조하여 동일함을 확인. 사용자 지정 평촌센텀퍼스트 1위 유지.
- **운영 사이트 및 master 미수정.** 분석 브랜치에 자료만 추가.
- **엄격한 한계:** 국토부 원본 매매계약 취소, 직거래, 층, 동, 계약 당사자 유형을 5,630개 모두 외부 대조한 결과가 아님. 정비사업 분담금도 독립 검증 전이며 '순위 확정'으로 주장할 수 없음.

## 방법 및 해석

1. **동일 단지 가격 역전**: 동일 이름/지역에서 큰 평형의 총액이 작은 평형보다 3% 초과 저렴할 때 각 평형에 주의 표시. 평면, 층, 대지지분, 거래표본·직거래의 차이로 정당화될 수 있어 오류로 단정하지 않음.
2. **근거리 비교**: 좌표상 1.2km 이내, 공급면적 차이 3평 이하, 준공연도 차이 8년 이하, 비교단지의 12개월 거래 5건 이상인 다른 단지를 최대 12곳 선택. 최소 3개일 때 가격/공급평 중앙값과 대상 가격/공급평 차이를 계산. 공급면적 변환과 사업성, 학군, 브랜드는 별도 조정하지 않았으므로 가격괴리 = 저평가·고평가 확정이 아님.
3. **조건 우세 후순위 단지**: 원래 순위가 100계단 이상 낮으면서 1.2km 이내, 공급평 차이 3평 이하, 두 단지 각 12개월 거래 5건 이상, 후순위가 대상 대비 평당 10% 이상 저렴하고 입지지표 1점 이상 높고 준공연도 2년 이상 뒤처지지 않으며 세대수 대상의 75% 이상일 때 표시. 질적 가치나 재건축 등 정성 근거를 제외한 **순위 의문 후보**.
4. **저표본·제로점수·오래된 거래**: 각 열에 비중복 경고. 우선순위는 단순 가중 트리아지일 뿐 법적/시장 가치 판단 아님.
5. **제안 순위**: 신규 감사 결과는 **확정 신규 순위를 만들지 않음**. 기존 A/B 참고순위만 원 자료에서 보존. 국토부 실거래 취소/직거래 원본, 단지 식별, 사업성, 층·향, 학군을 검증하지 않은 상태에서 1위부터 5,630위까지 정확한 확정 순위는 허위 정밀도가 됨.

## 후속으로 반드시 필요한 외부 검증

- 국토교통부 실거래가 공개시스템 계약일별 원본에서 2025-11~2026-11 취소·직거래·층·신고일과 전용면적을 대조한 재집계.
- 2,574개 단지 각각의 토지 지분, 공시된 정비사업 단계·추정 분담금, 오피스텔/임대/분양전환 특성의 실제 확인.
- 국토부가 공개하는 실거래 가격은 등기·해제 정보 등으로 계속 수정될 수 있음.

**결론:** 5,630개 평형 자체의 정량 교차감사는 추가로 수행했지만, 전수 **외부 독립 검증** 및 **최종 확정 순위**는 끝나지 않음. 운영 순위는 손대지 않음.
