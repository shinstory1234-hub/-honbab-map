## 실제 코드의 동률 구조
- public/apt-s4.js 161행: s4Total 함수가 구축 감점 후 값을 0~100 사이로 제한한다.
- 같은 파일 288~309행: 주상복합 감점 jb6, 전고점 미회복 감점 pk6 등을 반영한 뒤 다시 점수의 하한을 0으로 제한한다.
- 따라서 서로 다른 원시 평가치가 0점 동률이 될 수 있다. 3,586~5,630위는 기존 점수만으로 개별 서열의 우열을 설명할 수 없다. 0점 전부가 오류라는 뜻은 아니다.
