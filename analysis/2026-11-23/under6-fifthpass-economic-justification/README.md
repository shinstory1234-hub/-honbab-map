# 6억 이하 5,630개 평형: 5차 경제적 순위 정당성 심사 (2026-11-23)

**결론: 5,630개 전 평형에 대해 기존 순위가 맞는 근거와 반대 근거를 개별적으로 작성했으나, 기존의 1~5,630위 정확한 서열 전체를 경제적으로 입증하지 못했다.** 내부 순위 정당성 스트레스 테스트와 국토부 원본 계약 독립검증은 서로 다른 단계다. 현재 파일은 정량 비교에 따른 **잠정 심사표**이며 확정 투자순위나 투자수익률 예측이 아니다.

## 고정 조건
- **평촌센텀퍼스트 1위 유지.** 다른 모델의 순위와 무관하게 사용자 지정 1위로 남긴다.
- 매물 존재·매수가능성·청약가능성은 투자 가치의 순위 결정 요소에서 제외했다.
- 운영 `master`, 실제 사이트 시세·순위·배포는 **어느 것도 변경하지 않았다.** 별도 분석 브랜치에만 보고서를 저장했다.

## 자료와 새로 한 일
- 입력: 2026-11-20 6억 이하 순위 원본 및 2026-11-23 3차 위험검증과 4차 5,630행 개별 점수구조 진단.
- 검증: 5,630행을 기존 순위 1~5,630으로 연결, 3차 위험등급과 4차 입지·여력·세대수·준공년도·계약건수 및 모형 A/B 순위를 각 행에 결합했다.
- 그 위에 동일 행정동의 별도 단지 중 비슷한 면적·준공년도·입지 조건을 가진 평형을 조사하여 **각 평형의 현재 순위 지지 근거 / 반대 근거 / 변경 방향 / 구체적 확인 항목**을 기록했다.
- 이 비교는 이전 보고서의 위험등급을 다시 이름만 바꾼 것이 아니라, 기존 데이터의 유사 평형 가격과 하위순위 단지의 다지표 우위를 직접 비교한 추가 정량검사다.

**주의:** 77개는 서로 다른 **상위 순위 평형의 수**다. 앞선 3차의 62개 '비교 쌍' 또는 35개 '고유 단지 조합'과 정의가 다르다. 77개를 62개보다 많은 확정 순위오류라고 해석할 수 없다. 하향 재검토 후보 합계는 133+77 = **210개**다. 상향 251개도 확정 상향이 아니다.

기존 연구에서 보고한 '0점 2,045 + 동일단지 비영점 동률 2,189 = 4,234'에 더해, **서로 다른 단지의 비영점 동률 14평형**도 새로 발견했다. 전체 **4,248개 평형**은 정확히 같은 종합점수인 다른 평형이 존재한다. 이들 중 일부(325개)는 비교가격·모형 차이·다지표 역전으로 상향·하향 신호가 잡혀 위 표의 방향검토로 분류됐기 때문에 '동률로 정당화 불가' 3,923개와 혼동해서는 안 된다.

## 동일 행정동 비교 가격 규칙
**검증용 비교 평형의 조건**: 동일 행정동, 다른 단지, 공급면적 차이 6평 이내, 준공년도 차이 15년 이내, 입지점수 차이 15점 이내, 비교 평형의 최근 12개월 거래 최소 5건, 시세 양수.
- 각 기존 평형의 `가격만원 / 공급평`을 비교 평형들의 공급평당 가격 중앙값과 비교해 상대 가격차를 계산한다. 면적과 입지 차이를 **완전히 제거한 감정가가 아니다.**
- 동일 행정동 유사 **평형**이 3개 이상인 대상 3,597개, 1~2개 1,129개, 0개 904개. 동일 단지의 여러 평형은 이 숫자에서 제외했지만, 다른 한 단지의 여러 평형이 각각 포함될 수 있으므로 **고유 비교 단지 수로 오해하면 안 된다.**
- 구체적인 주차대수·평면·브랜드·정비사업 단계·대지지분·동·층·시야, 실제 전용면적이 추가로 일치하는 것은 아니다. 거래가 풍부해도 층·직거래·해제 검증은 별도 필요하다.
- `상대평당가격차%` 값이 낮으면 시장가격이 싸게 나타나는 **비교 신호**일 뿐, 저평가율이나 실현 수익률이 아니다.

## 하위 순위 단지의 객관 지표 동시 우위
같은 행정동, 서로 다른 단지, 양쪽 최근 12개월 5건 이상 거래 조건에서 다음 **다섯 기준을 동시에** 비교한다.
1. 하위 후보의 절대 가격이 같거나 더 낮다.
2. 하위 후보의 공급면적이 같거나 더 넓다.
3. 하위 후보의 입지점수가 같거나 더 높다.
4. 하위 후보의 준공년도가 같거나 더 최근이다.
5. 하위 후보의 세대수가 같거나 더 많다.

이때 하위 후보가 명확한 우위 단서이므로 기존 상위 평형 **77개를 하향 재검토**로 분류한다. 그러나 정비사업 권리가액·추정분담금·대지지분·재건축 진행속도나 특정 입지·상품 특성을 모두 포함하지 않았다. 따라서 이 77개는 **확정 오류 77개가 아니다.** 특히 산본주공11단지는 실제 정비사업 진행이 확인되므로 반드시 그 프리미엄의 원가와 순현재가치 검증을 선행해야 한다.

## 상·하향과 잠정 유지 판정 규칙
- **상향 재검토**: A/B 두 대체모형 순위가 모두 현재보다 최소 `max(250위, 현순위의 20%)`만큼 높고, 같은 동 유사비교 평형 3개 이상에 대해 공급평당가 8% 이상 저렴하며, 연간 거래 5건 이상이고 리치고 연결 기록이 있는 행. 하위 후보에 의한 객관적 서열 역전이 있으면 그 위험을 우선 판정한다.
- **하향 재검토(상대가격)**: A/B 두 모형이 모두 최소 같은 폭만큼 낮고, 같은 동 유사비교 3개 이상에 대해 공급평당가가 8% 이상 높고, 연간 거래 5건 이상이며 단지 연결 기록이 있는 행.
- **잠정 유지 논리**: 전 평형 0점·동률이 없고 최근 거래 5건 이상 및 최근 3개월 1건 이상, 단지 연결, A/B 각각 현순위와의 차이가 `max(150위, 현순위의 15%)` 이내, 3차 주요 가격·지표 역전 경고가 없으며 비교가격 괴리가 있으면 ±12% 이내인 행.
- 나머지는 확정 서열 근거 부족 또는 보류. 다른 평형과 동점인 행은 상대순위를 내부 점수만으로 판정하지 않는다.
- 이 임계치는 **추가 조사대상 우선순위를 정하기 위한 감사 규칙**이다. 과거 실현성과에 대한 인과적 검증이나 투자수익률을 최적화한 계수가 아니다. A/B 모형은 같은 가격 데이터를 쓰므로 독립 증거 2개가 아니다.

## 최종 순위를 실제로 확정하려면
1. 국토부 [아파트 매매 실거래 상세 자료 API](https://www.data.go.kr/data/15126468/openapi.do)에서 법정동·계약월별 거래를 조회한다. 해제여부·직거래·층·정확한 전용면적·계약 및 신고시점을 맞춘다. 원자료 사용 권한/인증 필요.
2. K-apt와 건축물대장, 단지 주소·필지·전용면적을 연결해 2,574개 단지의 이름과 실제 거래 단지를 확정한다.
3. 정비사업 공식 고시, 대지지분, 권리가액, 정비사업 분담금 추정치를 확인한다. 서울시 [정비사업 정보몽땅](https://cleanup.seoul.go.kr/) 등에서 추정치와 시점·불확실성을 구분한다.
4. 한 단지의 전체 가치 점수와 **평형별 상대가격·유동성·수요·대지지분 가치**를 분리한 뒤 동일 단지의 여러 평형끼리 실제 경쟁하는 대안을 검증한다.
5. 거래가 없는 경우 정확한 단일 대표가격을 강제로 채우지 않고 **순위 불확실·자료부족**으로 분리한다. 순위 유지/상향/하향/유보를 새 자료로 **다시** 판정한다.
