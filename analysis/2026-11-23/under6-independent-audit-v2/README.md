# 6억 이하 5,630개 평형의 추가 교차정합성 감사 — 2026-11-23

**확인 범위: 전체 행 5630개, 단지 2574개. 운영 브랜치는 변경하지 않음. 평촌센텀퍼스트 1위 고정. 매수 가능 여부 배제.**

> 본 조사는 기존 CSV를 처음부터 전체 읽고 별도 규칙으로 문제를 교차 검출한 **추가 정량·내부정합성 감사**다. 모든 평형의 국토부 원본 거래를 별도 독립 수집해서 취소·직거래·층·전용면적까지 검증한 **외부 독립 전수조사 완료는 아니다.** 5,630개 결과의 '외부원천검증' 열을 모두 미완료로 두었다. 원래 판정도 검증 전에는 확정 순위가 아니다.

## 검사 규칙
- 동일 '지역' 문자열, 공급평 ±3, 입주연도 ±10, **다른 단지**만 시장비교 후보로 사용. 후보의 12개월 거래가 5건 이상일 때에만 후보 포함. 5개 이상이면 단지별 공급평당 기준가격의 중위값을 구해 상대비율을 기록. 64% 이하 또는 145% 이상을 경고. **모두 사이트 내부 기준가격**이므로 국토부 거래 검증이 아님.
- 같은 단지에서 큰 평형이 작은 평형보다 10% 이상 저렴하거나, 면적 차 1~6평에서 가격이 60% 이상 높아지는 조합 조사. 면적·층·동·대지지분 차이 때문에 정상 거래일 수도 있어 오류 확정하지 않음.
- 다른 단지에서 동일 지역·공급평·기준가격·12개월 거래건수까지 동일하면서 가격이 백만원 단위의 정수가 아닌 행 우선 확인. 단지 별칭이나 통계 공유가 적절한지 원천 대조 필요.
- 기존 자료에서 0점 동률과 국토부 원거래 미검증은 독립 확인이 완료될 때까지 '순위 확정 불가'로 해석. 정비사업 후보는 공개 단계·대지지분·분담금 확인 전 하향 확정 금지.
