# 6억 이하 전 5,630개 평형 교차정합성 재감사 (2026-11-23)

**구분 필수: 5,630개 평형에 대한 새로운 데이터 내부 교차검증은 수행했지만, 국토교통부 계약 원천 5,630개 평형 전체를 별도 다운로드하여 취소·직거래·층·전용면적을 검증한 외부 독립 전수조사는 아니다. 이 파일의 숫자는 실제 거래 원본 검증 결과나 확정 순위가 아니다.**

- 기준: 2026-11-20 순위 스냅샷, 2026-11-23 앞선 A/B 재평가 CSV 6개를 새로 전체 읽어 검증
- 고정: 평촌센텀퍼스트 1위, 매수 가능 여부 제외
- 운영 브랜치·서비스 미수정
- 고유 평형 5630개, 단지 2574개

## 방법

- 동일 지역(원본 '지역' 완전일치), 공급평 ±3평, 준공연도 ±10년, 다른 단지, 최근 12개월 거래 ≥5건을 **비교 후보**로 추출. 후보 5개 이상인 경우 단지당 기준가격의 공급평당가 중위값과 비교하며 차이가 -36% 또는 +45% 이상이면 **검증 후보**로만 표시. 비교 가격은 모두 사이트 내부 기준가격이므로 독립 거래 검증이 아님.
- 같은 단지의 공급평 차이가 3평 이상일 때 큰 평형 가격이 10% 이상 낮은 조합, 또는 1~6평 차이에 큰 평형이 60% 이상 비싼 조합을 추출. 이는 면적 구조·신탁/재건축 프리미엄·최신 매매 유무로 실제 발생할 수 있어 바로 오류로 확정하지 않음.
- 가격·면적·지역·12개월 거래건수가 **모두 일치**하면서 단지명이 다른 행을 추출. 특히 가격이 100만원 단위 정수가 아닌 경우를 우선 점검. 같은 복합단지 다른 이름의 공유 데이터인지, 원천 잘못 복제인지 구분해야 함.
- 각 평형마다 기작성 판정과 분리하여 **정량적 유지 근거, 새로운 반대 신호, 수정 전 필수 조치**를 기록. 외부 직접 검증을 실행하지 못한 칸은 '미완료'로 표기.
- 이 감사의 우선순위는 **실제 부동산 투자 우열의 새 순위**가 아니다. 국토부 실거래 원본 대조 전에는 조정 숫자를 확정하지 않음.

## 특히 의심되는 문제

- **서로 다른 3개 단지: 군포 금정동 주공2-1단지 104·117·118·120·122위, 주공1단지 269·285·286·287·290위, 퇴계주공3단지1차 539·562·570·572·573위**가 같은 18·20·24·26·30평 기준가격과 **각각 같은 연간 거래건수**를 가진다. 단지별 가격·거래 통계가 공유된 이유를 검증해야 함. 이는 원본 CSV 관찰이며, 매핑 오류 확정은 아니다.
- **송내동 우성** 34평 58,347만원(1369위)과 50평 39,118만원(1368위): 같은 단지인데 큰 평형 가격이 33% 낮음. 상품 차이/무거래 과거값 여부 확인 필요.
- **은하수샛별5,6단지** 12평 29,240만원(4위)과 14평 50,000만원(9위): 2평 차이인데 71% 증가. 기준가격과 전용면적/거래원본 대조 우선.
- **산본주공11단지** 14평(13위) 16평(11위) 20평(24위)은 동네 비슷한 면적·연식 비교 후보보다 평당가가 높지만 재건축 가치가 반영될 수 있어 비싼 가격만으로 순위 하향을 확정하지 않음.
